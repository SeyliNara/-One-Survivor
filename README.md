# One Piece Survivors

Rogue-like façon Vampire Survivors en pixel art, inspiré de One Piece (jeu de fan non officiel, sans but lucratif).

- 6 héros avec arme prédéfinie (Luffy, Zoro, Nami, Usopp, Sanji, Franky)
- 7 mondes (Orange Town, Arlong Park, Alabasta, Enies Lobby, Marineford, Dressrosa, Wano), 3 boss chacun
- Une arme, un pouvoir ou une compétence à chaque niveau (5 armes max)
- Berries et améliorations permanentes, sauvegardées dans le navigateur

Un seul fichier : `index.html` (aucune dépendance, hormis la police « Press Start 2P » chargée depuis Google Fonts).

## Mettre le jeu en ligne avec GitHub Pages

1. Sur github.com, crée un dépôt **public** (par exemple `one-piece-survivors`).
2. **Add file → Upload files** : dépose `index.html` et `README.md`, puis **Commit changes**.
3. **Settings → Pages** : *Source* = *Deploy from a branch*, branche `main`, dossier `/ (root)`, puis **Save**.
4. Après environ une minute, le jeu est en ligne sur `https://TON-PSEUDO.github.io/one-piece-survivors/`.

Pour mettre à jour : remplace `index.html` dans le dépôt (**Add file → Upload files**) et valide.
